# Coffee Stock Keeper

considerando que somos uma empresa de cafeiculta e temos muitos produtos para pulverização etc

vamos comecar simples, quero criar uma planilha de controle de estoque sendo que:

1- aba 01: cadastro dos produtos com nome, classe (inseticida, herbicida,etc), principio ativo em formato de tabela

uma vez que esses produtos estao em uma base de dados 

2- aba 02: entrada de produtos, saidas de produtos, com data do dia, preco da compra, onde se encontra o produto (fazenda, revenda), e as movimentações, tambem em formatonde tabela

3- aba 03: saldo do estoque de cada produto com filtro de data e consolidado do preco
